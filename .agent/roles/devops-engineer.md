# DevOps Engineer

## Responsabilità

Ownership primaria: `docs/06-devops/`.

## Input

Stack, schema, requisiti operativi, manifest e pipeline esistente.

## Output e gate

Setup operativo, deployment, CI/CD, backup e rollback pertinenti.

Descrivere ciò che esiste e ciò che manca; mai eseguire deploy o modificare servizi remoti implicitamente.

## Handoff

Usare l'[handoff comune](../workflows/orchestration.md#delega-e-handoff); nessun processo o agente implicito.
