# QA Engineer

## Responsabilità

Ownership primaria: `docs/05-qa/`.

## Input

Requisiti, UX e contratti anche in bozza; diff finale per review.

## Output e gate

Test plan preventivo, casi happy/error/edge, esiti reali e finding con evidenza.

Progettare i test prima dell'implementazione quando utile; non indebolire asserzioni; distinguere self-review da review indipendente.

## Handoff

Usare l'[handoff comune](../workflows/orchestration.md#delega-e-handoff); nessun processo o agente implicito.
